Mini-CMS

Application Laravel de gestion d'articles — documentation du projet

Laravel 13PHP 8.3+SQLitePestSanctum

1. Présentation

Mini-CMS est une application web de gestion d'articles (posts) avec catégories, tags, authentification et une API REST. Elle a été construite au fil de 15 sessions de cours (Atelier Framework Côté Serveur — ISET Sidi Bouzid) et couvre le cycle complet d'une application Laravel : MVC, base de données, relations Eloquent, validation, autorisations, API et tests.

2. Fonctionnalités

Articles (Posts)

  • CRUD complet (création, lecture, modification, suppression)
  • Publication / dépublication
  • Archives par année
  • Filtrage par catégorie et tag
  • Articles "mes articles" (auteur)

Taxonomie

  • Catégories (admin CRUD)
  • Tags (admin CRUD)
  • Relation N:N posts-tags
  • Chargement anticipé (eager loading)

Authentification

  • Inscription / connexion manuelles
  • Rôles (author / admin)
  • Gates & Policies (PostPolicy)
  • Middleware admin, writable

API REST

  • Lecture publique (index/show)
  • CRUD protégé par Sanctum
  • API Resources (PostResource, CategoryResource)
  • Validation (Form Requests) + pagination

5. Structure du projet

app/
  Http/Controllers/        # Page, Post, Category, Tag, Auth, Api
  Http/Requests/           # Form Requests (web + Api)
  Http/Resources/          # PostResource, CategoryResource
  Http/Middleware/         # EnsureSiteIsWritable, EnsureUserIsAdmin
  Models/                  # User, Post, Category, Tag
  Policies/                # PostPolicy
config/site.php
database/
  migrations/              # users, posts, categories, tags, post_tag, personal_access_tokens
  factories/               # User, Post, Category, Tag
  seeders/                 # DatabaseSeeder, CategorySeeder, TagSeeder
resources/views/
  components/              # layout, navbar, post-card, post-form, ...
  posts/, admin/, auth/, errors/
routes/
  web.php                  # routes web
  api.php                  # routes API
tests/Feature/             # Pest tests

7. API REST

Préfixe /api. Lecture publique, écriture protégée par Sanctum.

MéthodeURIDescription
